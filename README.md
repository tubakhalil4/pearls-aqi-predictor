# 🌍 Pearls AQI Predictor

An end-to-end machine learning system for forecasting the Air Quality Index (AQI) for major cities in Pakistan for the next three days.

The project combines automated environmental data collection, feature engineering, machine learning, model management, explainable AI, and an interactive Streamlit dashboard.

---

## 📌 Project Overview

**Pearls AQI Predictor** predicts future AQI values for:

- Islamabad
- Karachi
- Lahore
- Peshawar

The system uses historical air-quality and weather data together with machine learning models to generate 24-hour, 48-hour, and 72-hour AQI forecasts.

The final forecasting model is **XGBoost**, selected because it achieved the best performance among the evaluated models.

## 🧠 Machine Learning Models

The project evaluates multiple machine learning approaches, including:

### XGBoost

XGBoost was selected as the final forecasting model because it achieved the strongest performance on the test dataset.

### Random Forest

Random Forest was trained and evaluated as an alternative ensemble model.

### LSTM

An LSTM-based approach was also explored as part of the project.

---

## 📊 Model Performance

### XGBoost

| Metric | Score |
|---|---:|
| MAE | 1.8409 |
| RMSE | 3.0999 |
| R² | 0.9934 |

### Random Forest

| Metric | Score |
|---|---:|
| MAE | 2.0517 |
| RMSE | 4.0670 |
| R² | 0.9886 |

XGBoost achieved the best overall performance and was therefore selected as the final forecasting model.

## 🔍 Explainable AI with SHAP

SHAP (SHapley Additive exPlanations) was used to explain predictions generated by the XGBoost model.

The most influential features identified by the SHAP analysis were:

| Rank | Feature |
|---:|---|
| 1 | aqi_rolling_6h |
| 2 | aqi_change_rate |
| 3 | pm2_5 |
| 4 | hour |
| 5 | ozone |
| 6 | pressure |
| 7 | temperature |
| 8 | humidity |
| 9 | nitrogen_dioxide |
| 10 | month |

The SHAP analysis provides insight into which features contribute most strongly to AQI predictions.

## 🌦️ Data Sources

The project uses environmental data from the **Open-Meteo APIs**.

### Weather Variables

- Temperature
- Relative humidity
- Wind speed
- Wind direction
- Atmospheric pressure
- Precipitation

### Air Quality Variables

- PM2.5
- PM10
- Carbon monoxide
- Nitrogen dioxide
- Ozone
- Sulphur dioxide

The project uses Open-Meteo's pre-computed AQI for the historical dataset rather than manually calculating AQI.

---

## ⚙️ Feature Engineering

The project transforms raw environmental data into machine-learning-ready features.

### Weather Features

- `temperature`
- `humidity`
- `wind_speed`
- `wind_direction`
- `pressure`
- `rain`

### Air Quality Features

- `pm2_5`
- `pm10`
- `carbon_monoxide`
- `nitrogen_dioxide`
- `ozone`
- `sulphur_dioxide`

### Time Features

- `hour`
- `day`
- `month`
- `day_of_week`

### AQI-derived Features

- `aqi_change_rate`
- `aqi_rolling_6h`

These features allow the model to capture both environmental conditions and recent AQI behavior.
